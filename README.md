# 単語帳 — Japanese–Thai Flashcards

เว็บฝึกคำศัพท์ญี่ปุ่น–ไทย (HTML + CSS + JavaScript ล้วน, ไม่มี Backend) เก็บข้อมูลใน **IndexedDB** ของเบราว์เซอร์

## ไฟล์ในโปรเจกต์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บ |
| `style.css` | ธีม Modern Japanese Minimalist (ขาว/ครีม/แดงญี่ปุ่น/เทาอ่อน), Responsive |
| `db.js` | ชั้นจัดเก็บ IndexedDB (โฟลเดอร์, คำศัพท์, นำเข้า, สำรอง JSON) |
| `import.js` | อ่าน/ตรวจสอบ Excel (ชีต Vocabulary, จับคู่คอลัมน์จากชื่อหัวตาราง) |
| `script.js` | UI, Flashcard, ระบบทบทวน, รายการคำศัพท์, จัดการโฟลเดอร์, ส่งออก |
| `Japanese_Thai_Vocabulary_Template.xlsx` | Template (มีแถวตัวอย่าง 3 แถว ลบก่อนใช้จริง) |

## วิธีเปิดใช้งาน (ทีละขั้นตอน)
1. แตกไฟล์ ZIP ไว้ในโฟลเดอร์ใดก็ได้
2. **แนะนำให้เปิดผ่าน Local Server** (เสถียรที่สุดสำหรับ IndexedDB):
   - เปิด Terminal/Command Prompt ในโฟลเดอร์โปรเจกต์ แล้วรัน `python -m http.server 8000`
   - เปิดเบราว์เซอร์ไปที่ `http://localhost:8000`
   - (ทางเลือก) ดับเบิลคลิก `index.html` เปิดตรง ๆ ก็ทำงานได้ใน Chrome/Edge/Firefox แต่ Safari อาจจำกัด IndexedDB บน `file://`
3. **ต้องมีอินเทอร์เน็ตครั้งแรก** เพื่อโหลด 2 อย่างจาก CDN: ไลบรารี SheetJS (นำเข้า/ส่งออก Excel) และฟอนต์ Google Fonts
   - ใช้ **Offline ได้เต็มรูปแบบ** ต่อเมื่อดาวน์โหลด `xlsx.full.min.js` (SheetJS 0.18.5) มาวางที่ `libs/xlsx.full.min.js` — หน้าเว็บจะใช้ไฟล์นี้อัตโนมัติถ้า CDN โหลดไม่ได้ (ฟอนต์จะสลับเป็นฟอนต์ระบบ)
   - ส่วนที่ไม่ใช้ Excel (Flashcard, ทบทวน, เพิ่ม/แก้ไข/ลบ, JSON backup) ไม่ต้องพึ่ง SheetJS

## นำเข้า `Japanese_Thai_Vocabulary_Template.xlsx`
1. เปิด Template → กรอกที่ชีต **Vocabulary** ตั้งแต่แถว 2 (แถวแรกคือชื่อคอลัมน์: Folder, Japanese, Kana Reading, Thai Meaning, Example Japanese, Example Thai, JLPT Level, Romaji, Notes) — ลบแถวตัวอย่างออกก่อน
2. ในเว็บกด **Import Excel** → เลือกไฟล์ (ไฟล์ต้นฉบับไม่ถูกแก้ไข)
3. ตรวจ **หน้าตัวอย่าง**: จำนวนแถวที่พบ / ถูกต้อง / ผิดพลาด (บอกเลขแถว) / คำใหม่ / คำซ้ำ
4. เลือกนโยบายคำซ้ำ (ซ้ำ = Folder + Japanese + Kana เหมือนกัน):
   เพิ่มเฉพาะคำใหม่ · เพิ่มใหม่+อัปเดตของเดิม (คงสถานะการเรียน) · เพิ่มทั้งหมดแม้ซ้ำ
5. กดยืนยัน → ดูหน้าสรุปผล
- ต้องมีคอลัมน์ Japanese และ Thai Meaning; คอลัมน์อื่นเว้นว่างได้; ไม่มี Folder → `Uncategorized`; สลับลำดับคอลัมน์ได้เพราะอ่านจากชื่อหัวตาราง

## เพิ่มคำศัพท์ในอนาคต
- หน้าเว็บ: ปุ่ม **＋ เพิ่มคำศัพท์** (มี "บันทึกและเพิ่มต่อ")
- หรือเพิ่มแถวใน Excel แล้ว Import ซ้ำ (เลือก "เพิ่มเฉพาะคำใหม่")
- ย้ายโฟลเดอร์: ติ๊กเลือกคำในหน้า คำศัพท์ → "ย้ายไปโฟลเดอร์…" หรือแก้ไขคำทีละคำ

## Backup / กู้คืน
- เมนู **สำรองข้อมูล** → **Export JSON** (คำศัพท์ + โฟลเดอร์ + สถานะการเรียน) เก็บไฟล์ไว้เป็นระยะ
- กู้คืน: **Import JSON** → เลือก "รวมข้อมูล" (ไม่ลบของเดิม) หรือ "เขียนทับ" (มีหน้าต่างยืนยัน)
- Export Excel (ทั้งหมด/เฉพาะโฟลเดอร์) ใช้คอลัมน์เดียวกับ Template
- ⚠️ ข้อมูลอยู่ในเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ซิงก์ข้ามเครื่อง และหายได้ถ้าล้างข้อมูลเว็บไซต์/โหมด Private

## การทำงานของระบบฝึกจำ
- 1 รอบ = แต่ละคำออกมา **ครั้งเดียว** ไม่ซ้ำ; เริ่มรอบใหม่จะสุ่มลำดับใหม่
- คำที่ประเมิน *จำไม่ได้/ยังไม่แม่น* มีโอกาสถูกสุ่มขึ้นก่อนในรอบถัดไป (ถ่วงน้ำหนัก 4× / 2.5×) — เป็นการถ่วงน้ำหนักการสุ่ม **ไม่ใช่** อัลกอริทึม Spaced Repetition เต็มรูปแบบ (ไม่มีกำหนดวันทบทวน)
- จบรอบแล้วเลือก "ทบทวนคำที่ยังไม่แม่นในรอบนี้" ได้
- เพิ่มคำระหว่างเรียน: ลำดับการ์ดปัจจุบันไม่เปลี่ยน มีแถบแจ้งให้เริ่มรอบใหม่
- โหมด Random Practice สุ่มครั้งละ 20 คำ (ค่าคงที่ `RANDOM_COUNT` ใน `script.js`)
- คีย์ลัด: Space = พลิก, ← / → = ก่อนหน้า/ถัดไป
- เสียงอ่านใช้ Web Speech API ของเบราว์เซอร์ ต้องมี Voice ภาษาญี่ปุ่นในระบบ

## ข้อจำกัดที่ทราบ / สถานะการทดสอบ
- ทดสอบอัตโนมัติบน Chromium (headless) ครอบคลุม: IndexedDB, เพิ่ม/แก้ไข/ลบ, ย้าย, โฟลเดอร์ (เปลี่ยนชื่อ/ลบ 2 แบบ), ค้นหา, การสุ่มไม่ซ้ำ, โหมดทบทวน, บันทึกผล, รีโหลดหน้า, JSON backup/restore, นำเข้า 6,000 แถว (~2 วินาที), Responsive มือถือ
- **ยังไม่ได้ทดสอบ**: การอ่านไฟล์ `.xlsx` จริงด้วย SheetJS และการเขียนไฟล์ Export `.xlsx` (สภาพแวดล้อมทดสอบไม่มีอินเทอร์เน็ตจึงโหลด SheetJS ไม่ได้ — ตรรกะตรวจสอบ/จับคู่คอลัมน์ทดสอบกับข้อมูลที่อ่านจาก Template แล้ว) รวมถึงเสียงอ่าน และเบราว์เซอร์ Safari/Firefox — กรุณาลองนำเข้า Template ของคุณ 1 ครั้งและแจ้งหากพบปัญหา
- รองรับไฟล์ `.xls` ผ่าน SheetJS แต่ยังไม่ได้ทดสอบกับไฟล์จริง
